Configuración del dispositivo de red

Producto 5 — Transformación de XML mediante CSS y JavaScript

Acerca de esta página

Esta página web muestra la configuración actual del dispositivo de red almacenada en el archivo red.xml generado en el Producto 4. Al pulsar el botón inferior, JavaScript carga el archivo XML, lo procesa y lo presenta formateado con la hoja de estilos estilos.css en un formato legible para el usuario humano.
